# AHS Twin Towers

Static landing page for AHS Twin Towers by Elite Property DXB.

## Run locally

Run `python -m http.server 8000` in this folder, then open http://localhost:8000.

The website has no build step. `index.html`, `style.css`, `app.js`, and `assets/` can be hosted directly on any static hosting provider.

Enquiries use the supplied Elite Property DXB email, telephone and WhatsApp details. The form prepares an email in the visitor's email app; it does not store submissions.

Project renders, film, logos, floor plans and brochure originate from the supplied AHS Properties agent pack. All project prices and specifications are indicative and subject to developer confirmation.
